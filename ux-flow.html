Voter Pledge Registration - UX Flow

Preview the complete user journey in one browser page.

Open Registration App Start at Mobile Verification

1) Mobile Number Entry

User lands on the first screen with Election Commission branding and enters a 10-digit mobile number.

Input: Mobile Number
↓

2) OTP Sent and OTP Field Shown

After clicking "Send OTP", OTP field appears and SMS OTP is sent. User enters OTP and verifies it.

Action: Send OTP + Verify OTP
↓

3) Personal Details Form

On successful OTP verification, user enters name, email ID, region, and city.

Fields: Name, Email, Region, City
↓

4) Consent Form

User reads pledge text and must acknowledge via checkbox to continue.

Required: Consent Checkbox
↓

5) Certificate Preview and Download

User sees certificate of appreciation preview and can download it.

Output: Certificate Preview + Download
